落地节点的定义很短：**流量离开代理网络、进入目标网站之前的最后一台服务器。** 但它决定的东西很多，选机场时很多纠结最终都落在这里。

## 目标网站看到的是谁

你访问一个网站时，对方记录的来源 IP 是落地服务器的地址，不是你家宽带，也不是中间的入口。所以：

- 落地在哪个地区，网站就倾向于把你当作那个地区的访问者。
- 落地 IP 属于哪类网络，比如 [原生IP](/glossary/native-ip/) 还是机房 IP，会影响部分服务对你的判断。
- 同一台落地被很多人共用时，别人的行为也可能牵连到你，这是共享出口的天然特点。

## 落地决定了哪几件事

| 方面 | 受落地影响的程度 | 说明 |
|---|---|---|
| 可访问的服务 | 高 | 部分服务对地区有限制，以各服务官方公布的支持地区为准 |
| 延迟 | 中到高 | 落地越远，物理往返通常越长，参见 [香港节点机场](/guides/xianggang-jiedian-jichang/)、[美国节点机场](/guides/meiguo-jiedian-jichang/) |
| 目标网站的风控 | 中 | 与 IP 类型、历史使用情况有关 |
| 你到入口的体验 | 低 | 这一段取决于入口和你的网络 |

## 入口与落地，两个别混的词

有 [中转线路](/glossary/relay-route/) 时，节点名通常是“入口到落地”的组合；没有中转的直连节点，入口和落地合一。两个词的分工：

- **入口**：你连的第一站，决定“连得顺不顺”。
- **落地**：目标网站看到的最后一站，决定“能访问什么”。

节点名里的地区，**通常指落地所在地，但也有服务商标成入口地区**，不确定就问客服。
