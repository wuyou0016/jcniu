这两个模式的区别，一个比喻就够：**全局模式是“所有人都走同一个门”，规则模式是“门口有保安，按名单分流”。** 门口有没有保安，决定了你的日常体验。

## 两种模式各自在做什么

- **全局模式**：不看目的地，所有流量都走你选中的那个 [节点](/glossary/proxy-node/)。
- **规则模式**：按规则列表从上到下匹配，命中“直连”的走本地网络，命中“代理”的走节点，没命中的由最后的兜底规则处理。
- **直连模式**（Clash 系常见）：所有流量都不走代理，相当于暂时关掉。

Shadowrocket 里类似的入口叫“全局路由”，常见选项有配置、代理、直连等，具体名称和选项以应用内显示为准。

## 日常该用哪个：一张对照表

| 场景 | 更适合 | 原因 |
|---|---|---|
| 日常上网，国内外混用 | 规则模式 | 国内站点直连，省流量也更顺 |
| 临时排查“连上了却打不开” | 全局模式 | 先排除规则不全的可能 |
| 需要所有流量都走节点 | 全局模式或 [TUN模式](/glossary/tun-mode/) | 避免漏网 |
| 暂时不想用代理 | 直连模式 | 比退出客户端更方便 |
| 访问内网、打印机等局域网设备 | 规则模式 | 局域网通常需要直连规则，全局模式下可能受影响 |

## 把全局模式当成“排错开关”

“已连接但无法上网”时，可以这样判断：

1. 切到全局模式，选一个确认可用的节点，打开几个站点。
2. 全局能打开、规则不能：问题多半在**规则**，比如规则集过旧、兜底规则指向直连。
3. 全局也打不开：问题更可能在节点、订阅、系统代理或 DNS，继续看 [已连接但无法上网](/troubleshooting/yilianjie-dan-meiwang/)。
4. 排查完记得切回规则模式，别一直在全局状态下使用。

## 规则模式常见的 3 个坑

- **规则集没更新**：新出现的站点没有被收录，被当成直连处理而打不开。
- **兜底规则选错**：最后一条规则指向直连时，没命中规则的站点全部直连。
- **策略组选了失效节点**：看起来连上了，实际用的是不通的节点，需要回到节点列表检查。

规则怎么写、规则集怎么挂、策略组怎么用，见 [分流规则](/tutorials/mihomo-fenliu-guize/)。

## 全局模式的两个代价

- **国内站点被绕路**：访问国内服务也经过海外节点，体验往往更差。
- **部分国内服务可能因为 IP 地区异常而触发风控**：这类情况因服务而异，不必恐慌，切回规则模式通常可以恢复。

在 Clash Verge 里切换模式的具体位置，见 [Clash Verge导入订阅教程](/tutorials/clash-verge-daoru-dingyue/)；在小火箭里设置全局路由，见 [小火箭导入订阅教程](/tutorials/shadowrocket-daoru-dingyue/)。需要所有软件都走代理时，请参考 [TUN模式](/glossary/tun-mode/)。
