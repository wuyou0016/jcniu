机场设备数限制，大多数情况下不是“你一共能装几台”，而是“同一时间有几个来源在用这条订阅”。口径各家不同，有的按同时在线的出口 IP 数，有的按并发连接，有的按登录过的设备标识。买之前把这一点问清楚，比事后猜规则省事得多。

## 设备数限制到底在限什么

机场为什么要限制设备数？一条订阅被很多人同时使用，会占用服务器资源，也会让账号更容易被滥用。所以套餐里才有“最多 X 台设备”这样的说明。常见的计数口径有三种：

| 口径 | 怎么算 | 常见现象 |
|---|---|---|
| 同时在线的出口 IP | 看有多少个不同的出口地址同时在用订阅 | 同一个家庭网络下的多台设备通常共用一个出口，可能只算一个 |
| 并发连接数 | 看同时打开了多少条连接 | 设备不多但开了很多下载任务，也可能触发 |
| 设备标识 | 按客户端上报的标识计数 | 重装系统、换客户端会让数量变化 |

这三种在实际里经常混合出现，机场也不一定会写清楚。所以“3 台设备”这几个字只能当作粗略的参考。

## 哪些使用方式容易超限

下面是常见的、不涉及违规的“误触发”情况：

- **网络来回切换**：手机在 Wi-Fi 和移动网络之间切换，出口地址变化；
- **多个客户端同时在线**：电脑上装了两个客户端都在运行，或者手机和平板同时开着；
- **订阅转发给别人**：家人、朋友用同一条链接，实际是多个来源；
- **路由器加设备**：路由器上已经在用订阅，再在手机上直连，同一时间出现多个来源；
- **订阅链接泄露**：被不认识的人使用，你自己都没察觉，处理办法见 [订阅链接泄露了怎么办](/knowledge/dingyue-lianjie-anquan/)。

## 超限之后一般会发生什么

后果因机场而异，没有统一标准，下面是常见的几类，具体以服务条款为准：

1. **提示超限**：连接时提示设备数已满，需要等其他设备断开；
2. **暂时限速或断开部分连接**：一段时间后恢复；
3. **拒绝新的订阅更新**：更新订阅时返回错误，节点列表为空或不变；
4. **账号被限制**：多次、明显超限，可能被要求联系客服或暂停账号。

遇到更新订阅失败的情况，先别急着判断是设备数的问题，可以按 [订阅更新失败怎么办](/troubleshooting/dingyue-gengxin-shibai/) 里的步骤排除链接、套餐和网络原因。

## 多设备使用的合规做法

面对机场设备数限制，不去试探上限，也不用任何方式规避，下面是更稳妥的使用习惯：

1. **先弄清口径**：下单前问客服“按同时在线的出口 IP 还是设备标识算”；
2. **自己的设备自己管**：手机、电脑、平板，不用的那台及时退出连接，别长期挂着；
3. **同一台设备只保留一个客户端**：避免两个客户端各占一份；
4. **不转发订阅链接**：需要给家人使用的，看是否有合适的多设备套餐，而不是把自己的链接发出去；
5. **路由器和手机二选一**：在家用路由器统一出口的话，手机在家时尽量不要再单独连接。

多设备套餐里设备数、流量和倍率经常是一起变化的，选购时可以配合 [机场流量倍率怎么算](/knowledge/liuliang-beilv-jisuan/) 和 [机场价格换算器](/tools/cost-calculator/) 一起算。

## 几个常见家庭场景对照

| 场景 | 可能的计数结果 | 建议 |
|---|---|---|
| 手机、电脑、平板在同一个家庭 Wi-Fi 下同时使用 | 出口 IP 相同，按出口 IP 算通常只算一个来源 | 仍要看机场是否另有设备标识限制 |
| 手机在 Wi-Fi 和移动网络之间来回切换 | 短时间内出现两个出口地址 | 切换后不要频繁重连，观察是否被提示超限 |
| 家人用同一条订阅在不同地点使用 | 出现多个出口 IP | 超限风险高，按需购买多设备套餐，不要转发链接 |
| 路由器已经接入，手机在家又单独连接 | 同一时间出现多个来源 | 在家时关闭手机上的单独连接 |

这张表只是帮助理解“口径不同，结果就不同”，不能替代机场的条款，实际计数方式以套餐说明和客服答复为准。

## 买前要问清的几件事

- 设备数怎么计数：出口 IP、并发连接，还是设备标识；
- 超限的处理方式：提示、限速，还是限制账号；
- 订阅是否允许在路由器上使用，会不会额外占用设备数；
- 重置订阅链接后，旧设备是否需要重新导入；
- 是否有按设备数分档的套餐，价格差多少。

把这些写进你的笔记，下一次续费或换机场时直接对照，具体可以配合 [买机场前自检清单](/tools/airport-checklist/) 使用。

## 今天就做

1. 打开你的套餐说明，找到设备数那一行，确认写的是“同时在线”还是“设备总数”；
2. 数一下你日常同时在线的设备，看是否接近上限；
3. 不用的设备先退出连接。

还没选定机场的，先看 [机场推荐排行榜](/rankings/) 里各家资料写明了哪些规则。使用代理服务请遵守所在地法律法规和机场服务条款，机场牛不提供法律意见。
