faqs:
  - q: 梯子工具和机场是一回事吗？
    a: 不是一回事。梯子工具通常指装在你设备上的客户端软件，负责接管流量、分流和切换节点；机场是提供节点线路的服务商，通过订阅链接把节点交给客户端。两者缺一不可：只有客户端没有订阅，列表是空的；只有订阅没有客户端，链接本身无法直接使用。
  - q: 买了付费的客户端 App，为什么打开后没有节点可选？
    a: 因为这类客户端本身只是连接工具，并不自带线路。你还需要另外获得节点服务提供的订阅链接或节点配置，再导入客户端才有节点可选。购买客户端之前，先确认自己手上有没有可用的订阅，避免白花钱。
  - q: 手机和电脑能共用同一个订阅吗？
    a: 订阅链接本身通常可以导入到不同设备的客户端里，但能同时在线几台设备、是否限制设备数，取决于具体套餐，需要以服务商的官方说明为准。另外要确认服务商给的协议在两端客户端上都被支持，否则其中一端可能导入后节点显示不全。
  - q: 客户端应该去哪里下载才放心？
    a: 优先走客户端项目的官方发布渠道，比如官方 GitHub 仓库的发布页或对应应用商店的官方上架页，不要从转发的网盘、论坛附件或来路不明的修改版下载。机场牛各客户端专页里整理了下载渠道的判断方法，装之前先看一眼。
  - q: 我不知道机场用的是什么协议，客户端该怎么选？
    a: 可以先在客户端选择器里把协议选成不确定，按设备拿到一份通用的推荐；再去服务商的使用说明里确认协议类型。常见的 Clash 系客户端和 sing-box 覆盖面较广，新协议的支持程度则以客户端当前版本说明为准。
  - q: 换了新手机或新电脑，需要重新买节点服务吗？
    a: 通常不需要。节点服务跟着你的订阅走，不跟着设备走，在新设备上装好客户端、重新导入订阅链接就可以继续使用。动手前先确认套餐允许同时使用的设备数，旧设备不用了可以卸载客户端；如果担心旧设备上的订阅外泄，可以在服务商后台重置订阅链接。

梯子工具怎么选，先别急着翻推荐榜，先问自己一句：**我缺的是客户端，还是节点？** 这是两层完全不同的东西。客户端是装在设备上的软件，决定"怎么连"；节点服务是机场提供的线路，决定"连到哪"。大多数新手买错，都是把这两层混成了一件事。这篇文章帮你拆开看，缺哪层补哪层，最后用机场牛的客户端选择器收个尾。

## 梯子工具怎么选：先把「客户端和节点」拆成两层

先用一张表把两层的分工摆清楚：

| 层级 | 它解决的问题 | 常见形态 | 缺了会怎样 |
|---|---|---|---|
| 客户端 | 怎么连：接管流量、按规则分流、切换节点 | Clash 系、v2rayN、小火箭、sing-box 等软件 | 手里有订阅，却不知道怎么用 |
| 节点服务 | 连到哪：提供海外出口线路 | 机场通过订阅链接交付的一组节点 | 软件装好了，节点列表是空的 |

打个比方：客户端像一部手机，节点服务像运营商的网络。手机再贵，没有网络也打不出去；网络再好，没有手机也用不上。梯子工具这个说法本身很宽，有人指客户端，有人指整套服务，所以搜"梯子推荐"时，结果里常常把两层混着讲。你要做的第一步，就是在自己脑子里把它们分开。

> 一个简单的自测：打开你的客户端，如果节点列表里一个节点都没有，你缺的是节点；如果你手里有一串订阅链接却不知道往哪贴，你缺的是客户端。

## 缺哪层，补哪层：四种常见处境的做法

梯子工具怎么选，核心是先诊断、后下单。对照你现在手里的东西：

| 你现在的处境 | 该补什么 | 下一步 |
|---|---|---|
| 有订阅链接，没有客户端 | 客户端 | 按设备选客户端，见下一节 |
| 有客户端，没有节点 | 节点服务 | 先读 [机场怎么选](/guides/jichang-zenme-xuan/)，再下单 |
| 两样都没有 | 先节点，后客户端 | 先定服务，再按它的协议选客户端 |
| 两样都有，但连不上 | 都不用补 | 去排查，不是选购问题 |

三个要点：

- **两样都没有时，顺序别搞反。** 节点服务用什么协议，决定了哪些客户端能用。先买了客户端再找服务，容易碰到协议不兼容。协议之间的差别可以看 [VLESS、Trojan、Hysteria2 区别](/knowledge/vless-trojan-hysteria2-bijiao/)。
- **两样都有却连不上，别再买新东西。** 先看 [机场节点超时怎么办](/troubleshooting/jiedian-quanbu-chaoshi/) 这类排查清单，多数情况是订阅过期、系统时间不对或模式没开。
- **别把客户端当成"解决一切"的东西。** 客户端再好，也改变不了节点本身的线路质量。

## 按设备选客户端：常见搭配一览

客户端主要按设备挑。下面是常见搭配，具体下载渠道和设置，点进专页看：

| 设备 | 常见选择 | 说明 |
|---|---|---|
| Windows | [Clash Verge](/clients/clash-verge/)、[v2rayN](/clients/v2rayn/)、Mihomo Party | 图形界面成熟，导入订阅即用；细节见 [Windows 客户端教程](/clients/windows-jichang-kehuduan/) |
| Mac | Clash Verge、Mihomo Party、sing-box | 见 [Mac 客户端教程](/clients/mac-jichang-kehuduan/) |
| 安卓 | 基于 Mihomo 或 sing-box 的客户端、v2rayNG 等 | 选择较多，认准官方渠道，见 [安卓机场教程](/clients/android-jichang-jiaocheng/) |
| iPhone、iPad | [Shadowrocket 小火箭](/clients/shadowrocket/)、sing-box 的 iOS 客户端 | 小火箭是付费软件，下载条件和上架情况以 App Store 当前规则为准，见 [iOS 机场教程](/clients/ios-jichang-jiaocheng/) |
| 华为鸿蒙 | 以专页说明为准 | 系统与安卓生态的兼容情况会变化，见 [华为鸿蒙机场教程](/clients/harmonyos-jichang-jiaocheng/) |

选客户端有三个朴素的判断标准：

1. **还有人在维护。** 看项目最近有没有更新，没人维护的软件遇到新协议会跟不上。
2. **来路清楚。** 只认官方发布渠道，不用转手打包、"破解版""增强版"。
3. **你看得懂。** 新手优先选图形界面完整、导入订阅只需要粘贴链接的软件；配置文件驱动的内核留给有基础的人。

另外，客户端不是装得越多越好：一台设备留一个主力、一个备用就够了，装多了只会互相抢系统代理，反而添乱。

## 按需求选节点服务：先定用途，再看这 5 项

节点服务才是真正拉开体验差距的那一层。选之前先写下你的主要用途：日常浏览、工作办公、AI 工具、流媒体，还是游戏。用途不同，要看的重点也不同：

- **线路与地区**：延迟低的地区和出口通用度高的地区常常不是同一个，可以参考 [香港节点机场](/guides/xianggang-jiedian-jichang/)、[日本节点机场](/guides/riben-jiedian-jichang/)、[美国节点机场](/guides/meiguo-jiedian-jichang/) 三篇对比着读。
- **流量与到期方式**：流量怎么扣、倍率多少、到期后是否自动续费，都要在下单前问清。
- **协议与客户端兼容**：确认服务用的协议你的客户端支持，这是前面说的"别搞反顺序"的落点。
- **稳定性的核对方法**：看 [稳定机场怎么判断](/guides/wending-jichang-zenme-pan/)，学会自己核对，而不是只听宣传。
- **售后与透明度**：有没有清晰的使用说明、退款条款和联系方式。

想横向看各家公开资料，可以去 [机场推荐排行榜](/rankings/) 和 [机场对比](/compare/) 两个页面。至于"好用"到底怎么判断，机场牛专门写过 [好用的梯子判断标准](/guides/haoyong-de-tizi/)，6 个标准都是你能自己核对的。

## 5 种常见处境：梯子工具怎么选，按场景对号入座

前面讲的是通用判断，下面落到具体的人。看看你更像哪一种：

1. **如果你是刚入门、手里只有一部手机**，先别急着买任何客户端，也别急着买长期套餐。第一步是确认自己有没有可用的订阅，没有就先选一个月付小套餐。拿到订阅之后，再按设备去挑客户端，iPhone 用户要留意客户端的下载条件，以 App Store 当前规则为准。
2. **如果你是一台办公电脑加一部手机**，通常一份订阅就能覆盖两台设备，但同时在线几台要以套餐说明为准。建议先在电脑上装图形客户端把订阅调通，再把同一份订阅导入手机，出问题时容易分清是服务的问题还是设备的问题。
3. **如果你喜欢折腾，想让不同网站自动走不同出口**，就选基于 Mihomo 或 sing-box 内核的客户端，因为它们的分流规则和策略组更灵活。先把基础连接跑通，再去学 [分流规则怎么设](/tutorials/mihomo-fenliu-guize/)，别一上来就改配置文件。
4. **如果你是帮家里的长辈装，只要“点一下就能用”**，优先选界面完整、导入订阅只需粘贴链接的客户端，并且一台设备只装一个，避免互相抢系统代理。订阅链接由你保管，别发到聊天群里。
5. **如果你已经有节点服务，只是换了新电脑或新手机**，不需要重新买服务，只需要在新设备上装好客户端，重新导入订阅即可。动手之前先看一下套餐允许的设备数，别因为超限被服务商限制。

这 5 种处境的共同点是：**先问自己缺哪一层，再决定花钱的地方。** 把钱花在缺的那一层，比把钱花在“看起来更高级”的那一层划算得多。

## 和一体化 App 有什么区别：别把两类产品混着买

应用商店里常能看到另一类"打开就能连"的应用，线路由应用自己提供，你不需要订阅链接，也不用另外找客户端。这类产品买的是整套服务，省事，但通常不能导入第三方的订阅，线路和规则也由应用方决定。"客户端加节点服务"则是两层各自独立：客户端可以换，服务商也可以换，配置权在你自己手里。两类产品没有谁一定更好，关键是别混着理解，否则就会出现买了客户端却找不到节点的情况。更详细的对照见 [机场和VPN区别](/knowledge/jichang-vs-vpn/)。

## 4 个常见误区：买了 APP 没节点只是第一个

1. **买了付费客户端，以为自带线路。** 客户端只是工具，节点要另外获得。买之前先搞清楚自己买的是哪一层。
2. **把"客户端推荐"当成"节点推荐"。** 一篇文章说某客户端好用，并不等于它背后的节点好用，两件事要分开评价。
3. **同时开两个客户端。** 两个软件会抢着改系统代理设置，常见症状是显示已连接却打不开网页，排查方法见 [已连接但无法上网](/troubleshooting/yilianjie-dan-meiwang/)。
4. **随手装来路不明的客户端。** 客户端能看到你所有经过它的流量，来路不明的修改版风险很高，了解风险可以读 [机场安全吗](/warnings/jichang-anquan-yinsi/)。

另外还有一个容易被忽略的点：**订阅链接相当于你的使用凭证**，别随手发给别人，也别贴到公开场合，泄露后的处理见 [机场订阅链接安全](/knowledge/dingyue-lianjie-anquan/)。

## 小 C 买了客户端却没有节点：一次“缺哪层”的诊断（虚构举例）

先说明：下面的人物和经过纯属虚构，只用来演示判断过程，不对应任何真实用户或真实产品。

小 C 在应用商店里付费买了一款客户端，打开之后，节点列表空空如也。他第一反应是软件坏了，准备去申请退款。后来一位朋友问了他一个问题：“你手里有订阅链接吗？”他才意识到，自己买的只是“怎么连”这一层，“连到哪”这一层根本没有着落。

理清之后，小 C 的动作很简单：先停下来，不再买别的软件；选了一个月付的小套餐，从服务商后台复制订阅链接；回到客户端，按对应的导入教程粘贴并更新。第一次更新没成功，他检查后发现链接复制时带上了多余的空格，重新复制后节点就出来了。如果换成别的报错，也可以按 [订阅更新失败怎么办](/troubleshooting/dingyue-gengxin-shibai/) 里的几个原因逐条排查。

这个故事里小 C 犯的不是什么大错，只是把两层东西当成了一件事。他后来给自己定了一条规矩：**买任何东西之前，先写下“我缺的是哪一层”。** 这一句话，足够挡掉大多数冲动消费。

## 用客户端选择器，30 秒定下该装哪个

机场牛做了一个本地运行的小工具：[机场客户端选择器](/tools/client-picker/)。它的用法很简单：

1. 选你的设备：Windows、Mac、安卓、iPhone 或 iPad、华为鸿蒙、Linux。
2. 选订阅用的协议：VLESS、Trojan、Hysteria2、Shadowsocks，或者选"不确定"。
3. 页面直接列出推荐的客户端，并给出对应的教程入口。

几点说明：

- 不知道协议也没关系，先选"不确定"拿到一份通用推荐，再去服务商的使用说明里确认协议类型。
- 工具在浏览器本地运行，选择过程不会上传。
- 推荐是基于客户端的通用能力给出的，具体某个版本是否支持某种协议，以客户端当前版本和官方说明为准。
- 想把下单前要问的事一次过完，可以搭配 [买前自检清单](/tools/airport-checklist/) 使用。

## 梯子工具相关术语速查：8 个常见说法

读教程和看推荐时，下面这些词出现频率很高，放在一起对照最省事：

- **客户端**：装在设备上的软件，负责导入订阅、选择节点、决定哪些流量走代理，是“怎么连”这一层。
- **节点**：服务商在某个地区架设的服务器及其线路，是“连到哪”这一层，详见 [节点](/glossary/proxy-node/)。
- **订阅链接**：打包了所有节点信息的网址，客户端访问它就能拿到最新的节点列表，相当于你的使用凭证，详见 [订阅链接](/glossary/subscription-link/)。
- **协议**：客户端和节点之间通信的“语言”，常见的有 VLESS、Trojan、Hysteria2、Shadowsocks 等，客户端必须支持服务商使用的协议。
- **规则模式与全局模式**：前者按规则决定哪些流量走代理，后者让全部流量都走节点，新手日常建议用规则模式。
- **系统代理**：很多客户端靠它把浏览器的流量交给自己，开关没打开就会出现“显示已连接却打不开网页”。
- **TUN 模式**：通过虚拟网卡接管整机流量，适合不走系统代理的软件，详见 [TUN 模式](/glossary/tun-mode/)。
- **机场**：行业里对“提供节点订阅的服务商”的俗称，和现实中的机场没有关系。

这几个词弄清楚，再去读各客户端的专页，就不会被名词绊住。

## 今天就能做的 3 件事

梯子工具怎么选这个问题，落到行动上其实只有三步：

1. 打开客户端选择器，选好设备，把候选客户端记下来。
2. 回头看自己手里有没有可用的订阅；没有，就先读 [机场怎么选](/guides/jichang-zenme-xuan/)，再决定买什么。
3. 客户端只从官方渠道下载，导入订阅按对应教程走，比如 [Clash Verge 导入订阅教程](/tutorials/clash-verge-daoru-dingyue/)。

最后提醒一句：使用这些工具前请了解并遵守所在地的法律法规，机场牛不提供法律意见，文章只讲技术概念与选购思路。
