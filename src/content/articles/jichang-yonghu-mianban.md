机场用户面板怎么看，一句话概括：买完之后登录“用户中心”，最常用的是四个位置，分别看用量与到期、拿订阅链接、管设备和账号安全、联系客服。把这四个位置找到并记下来，日常遇到的大多数问题，比如流量不够、订阅更新失败、被提示超限，都能先自己定位。

## 先说明：栏目名是示例

很多机场使用类似的开源面板搭建用户中心，所以栏目名称大同小异，但具体名称和位置各家不同。下面写的是“常见叫法”，找不到时按“位置和含义”去找，不要纠结名字。

## 第一个位置：仪表盘，看用量和到期

登录后首页一般是概览，常见内容：

| 信息 | 含义 | 看什么 |
|---|---|---|
| 已用流量 / 总流量 | 当前周期的用量 | 快用完时提前处理，办法见 [机场流量用完了怎么办](/knowledge/liuliang-yongwan/) |
| 到期时间 | 套餐有效期 | 续费日期和自动续费情况 |
| 流量重置日 | 下一次清零的日期 | 不同机场规则不同，要看清 |
| 套餐名称 | 你当前的档位 | 确认和你购买的一致 |
| 公告 | 机场发布的通知 | 节点调整、维护、迁移都会先公告 |

养成一个习惯：每次续费或改套餐之后，回到概览确认到期时间和流量有没有按预期变化。

## 第二个位置：订阅页，拿链接和管理订阅

订阅页是最常用的位置，通常有这些功能：

1. **订阅链接**：复制后粘贴到客户端；有的页面会给多种格式的链接，或提供“一键导入”按钮；
2. **二维码**：手机客户端扫码导入，注意不要把二维码截图发给别人；
3. **重置订阅**：链接泄露或被他人使用时用；
4. **客户端下载入口**：有的机场会放官方推荐的客户端，下载前自己再核对来源。

导入的具体步骤，按客户端不同看 [Clash Verge 导入订阅教程](/tutorials/clash-verge-daoru-dingyue/)、[v2rayN 导入订阅教程](/tutorials/v2rayn-daoru-dingyue/) 或 [小火箭导入订阅教程](/tutorials/shadowrocket-daoru-dingyue/)。

重置订阅要谨慎，它会让旧链接立刻失效。重置前先确认：所有在用的设备都能重新导入；重置之后，把旧的备份链接删掉。订阅链接的安全问题，见 [订阅链接泄露了怎么办](/knowledge/dingyue-lianjie-anquan/)。

## 第三个位置：个人资料与账号安全

这里决定了账号被盗的风险，建议第一次登录就设置好：

- **修改初始密码**：用独立的强密码，不要和其他网站重复；
- **绑定或确认邮箱**：找回密码、接收通知都依赖它；
- **开启两步验证**：如果面板提供这个选项，就打开；
- **登录记录或在线设备**：有的面板能看到最近登录的设备，发现不认识的就重置订阅并改密码；
- **关于设备数**：同时在线的设备数怎么算，见 [机场设备数限制怎么算](/knowledge/shebei-shu-xianzhi/)。

## 第四个位置：订单、工单和邀请

| 栏目 | 用途 | 提示 |
|---|---|---|
| 订单 / 账单 | 查购买记录、支付状态 | 保留订单号，退款和纠纷都要用 |
| 工单 / 客服 | 提交问题 | 写清问题、时间和截图，遮住订阅链接 |
| 邀请 / 返利 | 推广活动 | 看清规则，不要为了返利转发自己的订阅 |
| 商店 / 购买 | 续费、升级、加购流量包 | 下单前截图保存套餐和价格 |

## 第一次登录要做的五件事

1. 改掉初始密码，换成独立的强密码；
2. 确认注册邮箱能正常收信，找回密码和到期提醒都依赖它；
3. 在仪表盘记下到期时间、流量总量和重置日；
4. 打开公告栏，看有没有关于节点调整、迁移的通知；
5. 把面板网址和客服入口存进书签，避免日后在搜索结果里点到仿冒页面。

## 遇到问题，从面板入手排查

| 现象 | 先去面板看什么 |
|---|---|
| 节点全部超时 | 套餐是否到期、流量是否用完，参见 [机场节点超时怎么办](/troubleshooting/jiedian-quanbu-chaoshi/) |
| 订阅更新失败 | 订阅链接是否被重置、公告里有没有迁移通知，参见 [订阅更新失败怎么办](/troubleshooting/dingyue-gengxin-shibai/) |
| 提示设备超限 | 在线设备数、有没有别人在用你的链接 |
| 流量消耗太快 | 当前周期用量曲线（如果有）、节点倍率 |

## 今天就做

1. 登录面板，找到上面四个位置，并把网址存进你的书签；
2. 改掉初始密码，确认邮箱可用；
3. 记下到期时间、重置日和设备数上限。

还在比较机场的，机场用户面板的功能是否完整、客服渠道是否清楚，也可以作为选择条件，先看 [机场推荐排行榜](/rankings/) 里的资料。使用代理服务请遵守所在地法律法规，机场牛不提供法律意见。
