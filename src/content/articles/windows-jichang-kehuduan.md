Windows客户端教程要回答的问题其实只有两个：你手里订阅是什么格式，你想要点点点还是写配置。先给结论：多数新手从 Clash Verge Rev 起步最顺；订阅是通用格式、习惯 V2Ray 体系的，选 v2rayN；想折腾配置的，再看 sing-box。下面给对照表、选择路径，以及 Windows 上独有的权限、系统代理冲突和杀毒软件问题。

> **一分钟速查**
> - 选客户端：订阅是 Clash 或 Mihomo 能读的格式，新手从 Clash Verge Rev 起步；订阅是通用格式、习惯 V2Ray 体系，选 v2rayN；
> - 选安装包：先在系统信息里看“系统类型”是 x64 还是 arm64，再去官方 Release 页面挑包；
> - 系统代理与 TUN：日常浏览只开系统代理，游戏、命令行这类不走系统代理的软件才考虑 TUN，TUN 通常需要管理员权限；
> - 防冲突：同一时间只留一个客户端运行，退出后上不了网，先检查系统代理有没有残留；
> - 被拦截：杀毒软件或 SmartScreen 弹窗时，先核对来源和校验值，只信任这一个程序，别关掉整个杀毒软件。

## Windows机场客户端对比：四类怎么选

先说明一件事：所谓“Windows机场客户端”，就是在电脑上用来导入机场订阅、切换节点的软件。它们大同小异，区别主要在内核、订阅格式和上手难度：

| 客户端 | 内核 | 常见订阅格式 | 上手难度 | 适合谁 |
|---|---|---|---|---|
| Clash Verge Rev | Mihomo | Clash 或 Mihomo 的 YAML | 低 | 大多数新手，详见 [Clash Verge下载](/clients/clash-verge/) |
| Mihomo Party | Mihomo | 同上 | 低 | 想换界面、想用覆写的人，详见 [Mihomo Party](/clients/mihomo-party/) |
| v2rayN | 以 Xray 为主，可选 sing-box 等 | 通用订阅 | 中 | 习惯 V2Ray 体系的人，详见 [v2rayN教程](/clients/v2rayn/) |
| sing-box | sing-box | JSON | 高 | 愿意读配置的进阶用户，详见 [Sing-box教程](/clients/sing-box/) |

订阅格式一列只是常见情况，以机场实际提供的为准；界面和功能会随版本变化，以软件内实际显示为准。另外还有一些基于 Mihomo 的跨平台新客户端，维护状态因项目而异，新装前先看仓库最近有没有更新。

选不动的时候，可以用站内的 [客户端选择器](/tools/client-picker/) 辅助判断。

## Windows客户端教程第一步：四个问题定下客户端

1. **订阅是什么格式？** Clash 或 Mihomo 能解析的格式，优先看 Mihomo 系；通用格式，优先看 v2rayN；格式不匹配时才考虑转换，转换的风险见 [订阅转换](/tutorials/dingyue-zhuanhuan/)。
2. **电脑是 x64 还是 arm64？** 设置里进入系统信息，看“系统类型”。选错架构，安装包会打不开。
3. **需不需要 TUN？** 只用浏览器，系统代理就够；命令行工具、游戏、不遵守系统代理的软件，才需要考虑 TUN。
4. **想点按钮还是写配置？** 前者选图形界面完整的客户端，后者再看 sing-box 这类配置驱动的方案。

如果你是第一次接触，没有特别需求：Clash Verge Rev 加规则模式加系统代理，先把一整条链路跑通，再谈优化。

## 下载与安装：x64、arm64 与管理员权限

下载只认各项目在 GitHub 上的官方 Release 页面，各自的入口和选包要点，已经分别放进了上面表格里的专篇，这里不重复。几个 Windows 上特有的细节：

- **用户账户控制（UAC）弹窗是正常的**：安装程序要写入系统目录或注册组件时，Windows 会弹窗确认。只有确认安装包来自官方 Release 时才点“是”，来路不明的包，弹窗就是最后一道关；
- **平时不必一直以管理员身份运行**：需要管理员权限的主要是 TUN 和类似“服务模式”的组件，客户端通常会在你开启相关功能时给出提示，按提示操作即可；
- **安装路径尽量简短、避开权限受限的目录**：便携版的程序要在自己的目录里写配置和日志，放在系统保护目录里可能写入失败；
- **升级前备份旧目录**：尤其是解压即用的类型，覆盖前先复制一份。

## 系统代理、TUN 与常见冲突

| 对比 | 系统代理 | TUN |
|---|---|---|
| 原理 | 修改 Windows 的代理设置，软件自愿遵守 | 创建虚拟网卡，在更底层接管流量 |
| 权限 | 普通权限即可 | 通常需要管理员权限或服务组件 |
| 覆盖面 | 浏览器基本能覆盖，命令行与部分应用不一定 | 覆盖面更广 |
| 适合 | 日常浏览 | 游戏、命令行、不走系统代理的软件 |

TUN 的开启步骤和常见坑，见 [TUN模式设置](/tutorials/tun-mode-setup/)。Windows 上最常见的冲突有四种：

1. **多个客户端同时在跑**：谁后启动，谁就覆盖前一个的系统代理，现象是时通时不通。排查期间一次只留一个；
2. **浏览器里的代理扩展**：扩展的设置优先于系统代理，两层叠在一起，排查起来会很糟心；
3. **代理设置残留**：客户端崩溃或被强制结束后，系统代理可能留在“开”的状态，所有网页都打不开。到 Windows 设置的“网络和 Internet”里找到代理页面，把“使用代理服务器”关掉；
4. **商店应用不走代理**：部分商店应用对访问本机代理有限制，系统代理对它们不一定生效。改用 TUN，或使用客户端自带的类似回环豁免的工具，具体入口以客户端为准。

域名解析是否走了代理也会影响体验，检查办法见 [DNS泄漏检测](/tutorials/dns-xielou-jiance/)。

## 杀毒软件误报和 SmartScreen：保守处理

两类拦截要分清：

- **SmartScreen 弹窗**（类似“Windows 已保护你的电脑”）：这是系统对新发布或下载量少的程序的提醒，不等于程序有毒。确认来源是官方 Release 后，才点击“更多信息”里出现的继续运行入口；
- **杀毒软件拦截或删除**：这类客户端会改系统代理、建虚拟网卡、常驻后台，行为特征很容易被判成可疑，所以被误报的情况并不少见。

处理的顺序是：

1. 确认安装包来自官方仓库，而不是网盘或群文件；
2. 有校验值就核对，对不上直接删除重下；
3. 到项目的问题区看看有没有同样的反馈；
4. 信任时只添加该程序或目录，不要关闭整个杀毒软件，也不要把整个下载文件夹加入白名单；
5. 来源说不清、校验对不上的包，一律不放行，宁可不用。

## 装好之后的 Windows 自查清单：十二条逐项核对

在 Windows 上，客户端本身很少“坏”，坏的多是它和系统、和别的软件之间的关系。下面这份清单就是围绕这些关系设计的，装好当天勾一遍，以后每次重装系统、换客户端，再勾一遍。

- [ ] 安装包来自对应项目官方仓库的 Release 页面，不是网盘或群文件里的包；
- [ ] 系统信息里的“系统类型”，和安装包文件名里的 x64、arm64 标记一致；
- [ ] 安装时遇到的 UAC 弹窗，是自己刚刚触发的，不是莫名其妙冒出来的；
- [ ] 便携版解压在普通的可写目录里，旧版本的目录已经备份；
- [ ] 订阅导入之后，节点列表不是空的；
- [ ] 模式是“规则”，系统代理已打开，并且用浏览器验证过；
- [ ] 展开任务栏右下角的隐藏图标，没有第二个代理客户端在运行；
- [ ] 浏览器里没有叠加代理类扩展，或者扩展已经设为跟随系统；
- [ ] 开 TUN 之前，已经知道它需要管理员权限或服务组件，也知道怎么把它关掉；
- [ ] 知道异常退出以后怎么清掉残留的系统代理：设置，网络和 Internet，代理页面；
- [ ] 杀毒软件里只对这个程序添加了信任，没有关闭杀毒软件，也没有把整个下载文件夹加入白名单；
- [ ] 开机自启按需设置，不需要的别开，免得和别的软件抢系统代理。

## 虚构案例：小 C 装了两个客户端，网页时通时不通是怎么回事

小 C 是虚构人物，案例只演示排查思路，不涉及任何测试数据，也不指向真实用户。

小 C 先装了一个客户端，用了几天觉得界面不顺手，又装了另一个，打算对照着用，两个都设了开机自启。过了几天，他碰到一个怪现象：网页时通时不通，重启电脑后好一阵、坏一阵，换了好几个节点也没用，他开始怀疑订阅出了问题。

后来他决定不再猜，按顺序查：

1. **看托盘图标**。展开任务栏右下角的隐藏图标，他发现两个客户端都在运行；
2. **看系统代理设置**。进入 Windows 设置的“网络和 Internet”，打开代理页面，发现代理地址指向的是其中一个客户端的本地端口，而那个客户端当时并没有加载可用的订阅；
3. **只留一个**。他先在其中一个客户端里关闭系统代理，再退出程序，保留另一个。退出后回到代理页面确认，代理开关已经还原；
4. **关掉多余的开机自启**。他在被退出的那个软件的设置里取消了开机自启，以免重启后又变成两个同时跑；
5. **再验证**。重新打开留下的客户端，规则模式加系统代理，用浏览器验证，访问稳定下来。

问题从头到尾不在订阅，也不在节点，而是两个软件在抢同一份系统代理设置，谁后启动，谁就覆盖对方。这个虚构案例的启发有两点：其一，“时通时不通”先看是不是有多个客户端或浏览器扩展在抢代理，再去换节点；其二，排查期间一次只留一个客户端，把变量压到最少。

## 术语速查：选 Windows 客户端时绕不开的几个词

这几个词在教程和客户端界面里反复出现，术语页里有更完整的解释：

- [订阅链接](/glossary/subscription-link/)：机场给你的一条链接，客户端靠它拉取节点列表，等同于账号凭证；
- [节点](/glossary/proxy-node/)：订阅里的一条条线路，每个节点对应一个出口和一种协议；
- [全局模式与规则模式](/glossary/global-vs-rule-mode/)：全局是所有流量都走代理，规则是按规则分流，日常建议用规则；
- [TUN模式](/glossary/tun-mode/)：用虚拟网卡接管流量，覆盖面比系统代理广，在 Windows 上通常需要管理员权限或服务组件；
- [VLESS](/glossary/vless/) 与 [Hysteria2](/glossary/hysteria2/)：两种常见的节点协议，客户端能不能连上某个节点，要看所用内核是否支持它的协议。

另外三个没有术语页、但在 Windows 上经常碰到的词：**UAC** 是系统在安装或提权时弹出的确认窗口；**SmartScreen** 是系统对新发布或下载量少的程序给出的提醒，不等于程序有毒；**系统代理**是 Windows 设置里的那份代理配置，遵守它的软件才会走代理。

## 今天就能做的三件事

1. 按上面四个问题，先定下客户端，再去对应的专篇下载安装；
2. 一次只装一个，用规则模式加系统代理，把整条链路跑通，再决定开不开 TUN；
3. 客户端选好了，订阅才是消耗品，想比较不同机场的资料，去 [机场推荐排行榜](/rankings/) 或 [机场对比](/compare/) 看，别倒过来让客户端决定你买哪家。

这篇 Windows客户端教程 只讲通用思路，具体界面以各客户端实际显示为准。使用代理服务请遵守所在地法律法规，机场牛不提供法律意见。
