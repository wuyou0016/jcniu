这篇 v2rayN教程按使用顺序走一遍：怎么从官方渠道下载，订阅怎么导入，路由模式怎么选，系统代理和 TUN 什么时候该开。先说结论：v2rayN 是 Windows 上常见的免费开源图形客户端，上手不难，坑主要集中在三处，下错包、没开系统代理、把延迟测试当成速度测试。

## v2rayN 是什么，作为 Windows客户端适合谁

v2rayN 是一个开源的图形界面代理客户端，主要用在 Windows 上，据项目说明，新版本也提供了其他桌面系统的构建，具体以 Release 页面实际列出的文件为准。它本身不提供节点，需要配合机场给的订阅才能用。

几个关键特点，界面和功能会随版本变化，以软件内实际显示为准：

- **内核**：通常以 Xray 为主，较新的版本还可以选择 sing-box 等其他内核，切换入口在设置里；
- **协议**：VMess、VLESS、Trojan、Shadowsocks、Hysteria2 等常见协议，具体取决于所用内核和版本，协议之间的区别见 [VLESS、Trojan、Hysteria2 的区别](/knowledge/vless-trojan-hysteria2-bijiao/)；
- **订阅**：对通用订阅格式（编码后的节点链接列表）比较友好；机场只给了其他格式时，可能需要转换，风险见 [订阅转换](/tutorials/dingyue-zhuanhuan/)；
- **操作方式**：节点以表格显示，右键菜单能完成大部分操作，托盘图标负责系统代理和路由切换。

适合谁：手里的订阅是通用格式的人；喜欢节点列表直观、右键就能操作的人；已经熟悉 V2Ray 或 Xray 体系的人。如果你的订阅主要是 Clash 格式，或者更想要“规则集加策略组”的玩法，看 [Clash Verge下载](/clients/clash-verge/) 那一篇更对路。

## v2rayN下载：只走官方 GitHub Release

下载入口只认 [v2rayN 官方 Release 页面](https://github.com/2dust/v2rayN/releases)，核对仓库路径是 2dust/v2rayN。名字只差一个字母的 v2rayNG 是安卓版，别下错，安卓的选择见 [安卓机场教程](/clients/android-jichang-jiaocheng/)。

选包时对照这张表，文件名里的标记只做参考，以页面实际文件为准：

| 你的情况 | 怎么选 | 注意 |
|---|---|---|
| 常规 64 位 Windows | 选文件名带 windows 和 64 标记的包 | 设置 → 系统 → 系统信息里看“系统类型” |
| ARM 架构的 Windows | 选带 arm64 标记的包 | 选错架构会打不开 |
| 不想额外装运行库 | 优先选说明里写明已自带运行库的完整包 | 否则可能要先装对应的运行库，以 Release 说明为准 |

安装和使用习惯上有三点：

1. 通常是压缩包形式，解压后运行主程序，是否另有安装包看 Release 页面；
2. 解压到一个稳定的普通目录，不要放在需要管理员权限才能写入的地方，程序要在自己的目录里保存配置和日志；
3. 升级前把旧目录整体复制一份备份，再解压新版本，项目说明里写了覆盖升级的方法就按说明来。

另外，网盘、群文件里流传的“集成版”“免安装版”一概别用。客户端能看到你全部的流量去向，包被改过就等于把钥匙送人。校验值怎么核对，思路和 Clash Verge 那篇一致，不再重复。

## v2rayN订阅怎么导入：六步走通

这里只讲主线，每一步的常见报错和更新方式，放在单独的教程里：[v2rayN导入订阅](/tutorials/v2rayn-daoru-dingyue/)。界面文案以你看到的为准：

1. 在机场的用户面板里复制订阅链接，注意完整、别带空格；
2. 在主界面找到类似“订阅分组”的菜单，进入类似“订阅分组设置”的页面，点添加；
3. 备注填一个好认的名字，地址栏粘贴链接，保存；
4. 执行类似“更新订阅”的操作。首次导入时还没有可用节点，通常选“不通过代理”的方式；以后订阅域名需要走代理才能访问时，再选“通过代理”的方式；
5. 节点列表出现后，右键选一个节点，设为活动服务器；
6. 在托盘图标里把系统代理设为自动配置，再用浏览器验证。

节点列表里有类似“测试真连接”的功能，它比单纯的 ping 更接近实际可用性，但仍然只是握手类指标，数字小不等于下载快，完整的测速方法见 [机场测速工具](/guides/jichang-ceshu-gongju/)。

## 路由模式与分流设置：绕过大陆、黑名单、全局怎么选

路由决定哪些流量走代理、哪些直连。不同版本的预设名称不一样，下面按含义归类：

| 预设类型 | 含义 | 适合 |
|---|---|---|
| 绕过大陆类 | 国内地址直连，其余走代理 | 日常主力，大多数人选它 |
| 黑名单类 | 只有名单里的域名走代理，其余直连 | 只想代理少数站点 |
| 全局 | 所有流量都走代理 | 排错对照、临时需要 |
| 自定义路由 | 自己写规则 | 熟悉规则语法的进阶用户 |

有三点要留意：

- 预设会用到地理数据文件（用来判断一个地址在哪个区域），这些文件需要更新，软件里一般有类似“更新 Geo 文件”的入口。长期不更新，容易出现国内站点误走代理或反过来的情况；
- 路由里的域名解析策略，没有明确需求就保持默认；
- “规则”和“全局”的基本区别，看术语页 [全局模式与规则模式](/glossary/global-vs-rule-mode/)。Clash 系的规则集与策略组写法见 [分流规则](/tutorials/mihomo-fenliu-guize/)，思路相通，但 v2rayN 的路由是另一套界面，别把语法直接搬过来。

## 系统代理与 TUN：什么时候该开

系统代理改的是 Windows 的代理设置，只有遵守这个设置的软件才会走代理，浏览器通常遵守，命令行、部分游戏和一些应用不一定。TUN 则是创建虚拟网卡，在更底层接管流量，覆盖面更广。

| 场景 | 建议 |
|---|---|
| 日常浏览网页 | 系统代理够用 |
| 命令行工具、游戏、不走系统代理的软件 | 考虑 TUN |
| 系统自带商店里的部分应用 | 这类应用对本机代理有限制，用 TUN 通常更直接，以实际表现为准 |

较新的版本提供类似“启用 Tun”的开关，需要以管理员身份运行，开启后的具体行为以所用版本的说明为准。什么是 TUN、开启后可能遇到什么坑，见 [TUN模式设置](/tutorials/tun-mode-setup/)。

还有一个常见翻车点：正常退出会还原系统代理，异常退出或崩溃后，Windows 的代理设置可能残留，现象是所有网页都打不开。处理方法是到 Windows 设置的“网络和 Internet”里找到代理页面，把“使用代理服务器”的开关关掉。

## 五种处境怎么设置：v2rayN 用在你身上该怎么调

按“如果你是……就……，因为……”对号入座，找到最像自己的那一条。

- **如果你是 Windows 新手，只想让浏览器能上网**：节点选一个，路由选类似绕过大陆的预设，系统代理设为自动配置，其余保持默认。第一次别碰内核切换、自定义路由和 TUN，先让最短的那条链路跑通，再一项一项加功能；
- **如果你要用命令行、git 或各种包管理器**：这类工具大多不读 Windows 的系统代理，浏览器能上，它们照样连不上。思路有两个：开启 TUN，需要以管理员身份运行；或者在命令行窗口里设置代理环境变量，端口以软件设置里显示的本地监听端口为准。环境变量只对当前窗口有效，想一劳永逸，考虑 TUN，步骤见 [TUN模式设置](/tutorials/tun-mode-setup/)；
- **如果机场同时给了几种格式的订阅**：优先选和客户端匹配的那一种，不要为了“统一”去转换。转换会让订阅链接经过第三方，转换后的节点也得自己核对。通用格式在 v2rayN 里通常最省事，格式拿不准就先问机场；
- **如果导入后节点一大堆，不知道选哪个**：可以用“测试真连接”一类的功能，先把明显连不通的节点筛掉，但别拿延迟数字当速度排名。节点值不值得长期用，要看一段时间的使用观察，判断思路见 [稳定机场怎么判断](/guides/wending-jichang-zenme-pan/)；
- **如果你换了新电脑，或者要重装系统**：v2rayN 的配置存放在它自己的目录里，重装之前把整个目录备份一份，能少做很多重复工作。注意备份里含有订阅信息，压缩包别发给别人，也别传到公开的网盘。懒得备份也行，订阅链接从机场面板重新复制，导入一遍即可。

## 进阶：一个请求要经过哪几层，v2rayN 排错该从哪层查起

v2rayN 看起来是一个窗口，背后其实是一条链路。把链路理清，排错就不用靠猜。下面是通用的分层思路，具体名称和界面以所用版本为准：

| 层 | 在做什么 | 出问题时的典型表现 |
|---|---|---|
| 应用 | 浏览器、命令行或其他软件发出请求 | 个别软件走不了代理，别的都正常 |
| 本地入口 | 内核在本机监听的代理端口，等着软件把流量送过来 | 系统代理没开，或软件没有把流量送到这个端口 |
| 路由 | 按规则决定走代理、直连还是拦截 | 国内站点绕路，或该走代理的反而直连 |
| 出口（节点） | 按节点的协议把流量送往服务器 | 节点超时，部分节点连不上 |
| 订阅与账号 | 节点从哪来，套餐是否有效 | 节点列表为空，更新订阅报错 |

两种接入方式的区别，也能用这张表讲清。**系统代理**改的是“哪些软件会把流量送到本地入口”，软件不遵守，流量就不会进来；**TUN** 是从虚拟网卡一侧把流量接进来，不依赖软件是否遵守。所以“浏览器能上、命令行不行”，问题多半卡在第一层到第二层之间，改用 TUN 或者设置环境变量，补的就是这一段。

排错顺序建议从上往下：先看系统代理是否打开、本地入口是否在运行；再看路由有没有把目标选成直连；然后换一个节点对照；最后才去查订阅和账号。每一层只做一个改动，改完马上验证。

有两个细节值得提前知道。其一，路由规则通常按顺序匹配，靠前的先生效，所以自定义路由时，顺序本身就是配置的一部分。其二，路由设置里的域名解析策略，会影响基于 IP 的规则能不能命中域名类的流量，没有明确需求就保持默认。这套分层思路不适用的情况是：软件自己内置了代理设置、会绕开系统代理的，这类软件要到它自己的设置里去配，或者改用 TUN。以上细节以所用版本的官方说明为准。

## 术语速查：v2rayN 里常遇到的八个词

读 v2rayN 的界面和教程，下面这几个词会反复出现，每个都配了术语页，想深究就点进去：

- [订阅链接](/glossary/subscription-link/)：机场给你的一条链接，客户端靠它拉取节点列表，等同于账号凭证，要像密码一样保管；
- [节点](/glossary/proxy-node/)：订阅里的一条条线路，每个节点对应一个出口和一种协议；
- [全局模式与规则模式](/glossary/global-vs-rule-mode/)：全局是所有流量都走代理，规则是按规则分流，对应 v2rayN 里的全局和绕过大陆类预设；
- [TUN模式](/glossary/tun-mode/)：用虚拟网卡接管流量，覆盖面比系统代理更广，通常需要管理员权限；
- [VLESS](/glossary/vless/)：Xray 体系里很常见的节点协议，是否支持取决于所用内核和版本；
- [Trojan](/glossary/trojan-protocol/)：常见的节点协议之一，传输时使用 TLS 加密；
- [Hysteria2](/glossary/hysteria2/)：基于 QUIC 的较新协议，支持情况同样看内核和版本；
- [Shadowsocks](/glossary/shadowsocks/)：历史较久的常见协议，各类客户端基本都支持。

还有一个没有术语页但绕不开的词：**内核**。它是真正转发流量的引擎，v2rayN 通常以 Xray 为主，较新的版本可以切换到别的内核，切换前先看清楚当前节点用的协议，新内核是否支持。

2. 导入订阅，用类似绕过大陆的预设加自动系统代理，先让浏览器跑通；
3. 想确认自己选的客户端和订阅匹配，可以看 [v2rayN机场推荐](/guides/v2rayn-jichang-tuijian/)，对比不同机场的资料，则去 [机场推荐排行榜](/rankings/)。

软件界面、内核和功能会随版本变化，一切以项目官方说明为准。使用代理服务请遵守所在地法律法规，机场牛不提供法律意见。
